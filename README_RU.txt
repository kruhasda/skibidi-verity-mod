КАК ПОЛУЧИТЬ ГОТОВЫЙ .JAR ФАЙЛ МОДА (2 СПОСОБА):

СПОСОБ 1. Без установки программ на ПК (через GitHub за 2 минуты):
1. Создайте пустой репозиторий на https://github.com/new
2. Нажмите "uploading an existing file" и перетащите туда все папки и файлы из этого архива (включая папку .github).
3. Перейдите во вкладку "Actions" в вашем репозитории — GitHub сам запустит сборку мода!
4. Через 1-2 минуты нажмите на завершенную сборку и внизу в разделе "Artifacts" скачайте готовый .jar файл мода.

СПОСОБ 2. На своем компьютере (через IntelliJ IDEA или Gradle):
1. Распакуйте архив в любую папку.
2. Откройте папку как проект в бесплатной программе IntelliJ IDEA (она сама скачает Gradle и Java 17).
3. В панели Gradle справа выберите Tasks -> build -> build (или выполните команду `gradle build` в терминале).
4. Готовый мод появится в папке `build/libs/skibidi-verity-mod-1.0.0.jar`.
